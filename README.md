# 🧩 Wordscapes - Terminal Word Puzzle Game

A **C++ terminal-based word puzzle game** inspired by the popular mobile game *Wordscapes*. Players are challenged to form valid words using a given set of scrambled letters. The game validates words using a dictionary and rewards correct guesses, making it both fun and educational.

---

## 🎮 Game Modes

- **Classic Word Formation:** Players are given a shuffled set of characters and must create valid dictionary words from them.
- **Time-Free Mode:** No time pressure – play at your own pace and improve vocabulary.

---

## ✨ Features

- Word generation from a predefined character set
- Dictionary-based word validation (via `Dictionary.txt`)
- Tracks and displays found vs. total possible words
- ASCII-based user interface in terminal
- Replay option after each round

## 🚀 Getting Started

### ✅ Prerequisites

Ensure a C++ compiler is installed (e.g., `g++`, `clang++`, MSVC).

### ⚙️ Compile and Run (Linux/Windows/macOS)

``` 
g++ -o wordscapes Wordscapes.cpp
./wordscapes
```
Make sure Dictionary.txt is in the same directory as the executable.

## 🎯 How to Play
- Launch the program in your terminal.

- A set of scrambled letters will be displayed.

- Form valid words using the letters.

- Enter each guess one by one.

- The game will check your guess against the dictionary.
- Continue until all possible words are found or exit.

## 📌 Notes
- All valid words must be present in Dictionary.txt.

- The dictionary file can be extended with more words as needed.

- The game was designed with simplicity and modularity in mind for educational or recreational use.
